## 🍽 Dalouna Restaurant Website

This is a simple responsive website for *Dalouna Restaurant*, created as part of my web development assignment.

---

## 🌟 Features
- Clean and responsive design using *HTML5* and *CSS3*  
- Organized layout with semantic HTML structure  
- Sections included:
  - Home (Hero section)
  - About Us
  - Menu
  - Opening Hours
  - Location
  - Footer with GitHub link

---

## 💡 Purpose
This project was built to demonstrate:
- Understanding of *semantic HTML structure*
- Use of *Flexbox* for layout
- Implementation of *consistent styling* and design principles

---

## 🧩 Technologies Used
- HTML5  
- CSS3  
- Google Fonts (Rubik)
